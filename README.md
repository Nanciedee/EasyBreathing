# EasyBreathing — version intégrée

Fichiers : index.html, style.css, script.js et sessions.js.

Pour tester :
1. Décompressez tous les fichiers dans un même dossier.
2. Lancez un serveur local (par exemple Live Server dans VS Code).
3. Ouvrez index.html depuis ce serveur.

Le chargement de sessions.js utilise les modules JavaScript : l'ouverture directe en file:// peut être bloquée par certains navigateurs.
La progression et les notes sont enregistrées localement dans le navigateur.
